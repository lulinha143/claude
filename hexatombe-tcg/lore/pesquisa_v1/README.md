**Sobre a origem dos dados**
- A base é a [Ordem Paranormal Wiki](https://ordemparanormal.fandom.com/wiki/Hexatombe), lida pela API da wiki em 16/10/2026.
- Os relatórios foram montados com a ajuda de agentes de pesquisa, a partir dessas páginas.
- Referências no formato `[C9E7@4h46m]` significam: campanha 9 (Hexatombe), episódio 7, tempo citado pela wiki.
- Os episódios não foram assistidos. Trechos marcados como inferência, material extra ou sem referência devem ser tratados com essa ressalva.
